## How to Run

### Prerequisites

Install Java JDK 21 or another compatible Java version.

Check your installation:

```bash
java -version
javac -version
```

### Compile and Run

Clone the repository:

```bash
git clone https://github.com/sdharr/Java-DSA.git
```

Navigate into the project directory:

```bash
cd Java-DSA
```

Compile a Java file, for example:

```bash
javac -d bin src/bTwoSum.java
```

Run it:

```bash
java -cp bin bTwoSum
```

Replace `bTwoSum` with the class name of the solution you want to run.

Note: The `bin/` directory contains generated compilation files and is excluded from version control.
